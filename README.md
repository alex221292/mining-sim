# Mining Sim — Milestone 1

Песочница падающих материалов, Java 25. Нужны JDK 25, подключение к интернету при первом запуске и графическая среда.

```sh
./gradlew test
./gradlew build
./gradlew run
```

В Windows используйте `gradlew.bat` вместо `./gradlew` при необходимости. Gradle Wrapper скачает Gradle 9.2.1.

Левая кнопка мыши рисует, правая стирает; 1 — песок, 2 — вода, 3 — камень, 4 — дерево; пробел — пауза, N — один тик на паузе, C — очистить мир. Кисть заменяет существующий материал. Нажмите на поле, чтобы вернуть ему фокус клавиатуры.

Мир 400×300 закрыт по краям. Песок падает вниз или по диагонали и тонет в воде, меняясь с ней местами; вода течёт вниз или вбок; камень и дерево неподвижны. Остальные перемещения возможны только в пустые клетки, каждая частица перемещается не более одного раза за тик. Выбор направления воспроизводим при одинаковых начальном состоянии, seed и последовательности действий. Симуляция выполняется с фиксированным шагом 60 Гц и ограничением на догоняющие тики; вся работа с миром и интерфейсом происходит в потоке Swing. FPS и TPS отображаются отдельно.
