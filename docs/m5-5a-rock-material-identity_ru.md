# M5.5a — идентичность породы фиксированного блока

Четыре породы используют одинаковые правила опоры, задержки, падения и вытеснения воды. Стабильные ID клеток: STONE 1, GRANITE 8, LIMESTONE 9, MARBLE 10. Неизменяемый материал записи блока является источником идентичности; все клетки его области обязаны совпадать. Материал отображается в существующий `SubstanceId` M4.3d независимо от представления BLOCK и статической физической категории. Объекты на клетку не создаются. Исторические фрагменты, rigid body произвольной геометрии, инвентарь и модели массы не интегрированы. Будущая GRIT — сыпучие клетки того же вещества, ITEM — представление в инвентаре; здесь они не реализованы. Исторические плотности на физику блоков не влияют.

Клавиши 3, 7, 8, 9 выбирают STONE, GRANITE, LIMESTONE, MARBLE; F7 меняет размер блока, F8 создаёт прежний массив STONE. F3 показывает породу блока под курсором. Мазок поверх блока не перекрашивает его. Индивидуальная прочность, добыча и процедурная генерация разных пород не реализованы.

## Сохранения

MSIM v3 сохраняет структуру v2, но расширяет прежний байт вещества, допускавший только STONE: 0 STONE, 1 GRANITE, 2 LIMESTONE, 3 MARBLE. Клетки отдельно содержат указанные выше ID; при загрузке и сохранении отвергаются несогласованность, клетки породы без владельца, неизвестные ID и другие нарушения прежних инвариантов. Версия изменена, поскольку контракт v2 допускал только вещество 0. CRC, атомарная запись и перезапуск RNG с seed 12345 не менялись.

| Файл | Новое приложение | Приложение M5.4 |
|---|---|---|
| MSIM v1 | LEGACY, без миграции | LEGACY |
| MSIM v2 | фиксированные блоки STONE | фиксированные блоки STONE |
| MSIM v3 | четыре породы | отклоняется как неизвестная версия |

## Измерения

`gradlew.bat blockSupportBenchmark`, Corretto 25.0.5+10, 800×401, seed 12345, 20 прогревочных и 100 последовательных измеренных тиков, миллисекунды mean/p95/max. Сцена воды изменяется во время прогрева; одиночный запуск включает шум JVM и ОС и не определяет худший случай.

| Сцена | 8×8 | 4×4 |
|---|---|---|
| 1000 STONE | 0.829/1.020/1.592 | 0.866/0.903/0.992 |
| 1000 смешанных | 1.290/1.664/1.769 | 0.858/0.869/0.884 |
| STONE падение/вода | 1.188/1.553/1.615 | 0.841/0.926/0.942 |
| смешанные падение/вода | 1.184/1.548/1.599 | 0.844/0.935/0.950 |

Результат статического смешанного массива 8×8 выше в этом запуске; причина не установлена, обобщать его нельзя.

## Проверка

`gradlew.bat test build` проходит с Corretto 25. Focused-тесты проверяют смешанную опору, удаление и восстановление опоры, парный replay, сыпучее препятствие, вытеснение воды каждой породой с сохранением материалов, persistence смешанных состояний и отклонение повреждённых данных. Прежние тесты MSIM v1 LEGACY сохранены; дополнительно загружается образец, записанный настоящим сериализатором M5.4 v2. Для сравнения с baseline выполнены `gradlew.bat generationParityProbe -Pm54Baseline` и `gradlew.bat generationParityProbe`: из Git компилируются только исходные fixed-block и serializer, генерация и остальные зависимости не изменены. SHA-256 ID клеток в построчном порядке совпал для 128×129, seed 1, 71 и 12345 и обоих размеров. Те же отпечатки проверяются тестом; генератор не принимает выбранную кисть. Эта конечная выборка не доказывает совпадение для всех seed.

## Ручная приёмка (только пользователь)

Для каждого размера нарисовать все породы, проверить цвета и границы, построить смешанную конструкцию и удалить опору, уронить породы в воду, проверить F3 и save/load. Проверить привычную генерацию STONE по F8. Агент GUI не запускал.
