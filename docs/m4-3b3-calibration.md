# M4.3b.3 — reference calibration

`RockReferenceScenes.GAMEPLAY_STONE` is a named **gameplay fixture profile**, not measured or validated geological data: density 2500 kg/m³, Young modulus 1e8 Pa, tension 40000 Pa, compression 1e6 Pa, shear 40000 Pa, bending 40000 Pa, damage rate 0.5 s⁻¹. Gravity is 9.81 m/s², one cell is 0.1 m and one tick is 1/60 s. Both roof scenes use this exact profile, gravity, one-cell thickness and identical supports. This profile is local to reference scenes; it does not silently change the existing registry default. The fixed interaction/damage laws and clamped bedrock contacts are described in `m4-3b-damage.md`.

Coordinates increase right and downward. Roof fixtures: world `(span+5)×6`, bedrock y=5; stone roof x=2..2+span at y=2, pillars x=2 and x=2+span at y=3..4. Short span=4 (three cells between pillar centerlines); long span=12 (eleven). Thick roof uses the same span=12 and adds roof row y=1. World side boundaries are outside the pillars and add no support. Cantilevers: world `(length+5)×6`, roof x=2..2+length at y=2, pillar (2,3),(2,4), bedrock y=5. Island: world 7×6, stone (3,1),(4,1). All fits under 64 nodes. An oversized 65-stone fixture is explicitly tested in `RockDamageSystemTest`.

With Java 25, zero-based tick IDs, fixed 600-tick limit: short `CONVERGED`, 9 nodes/8 bonds, peak utilization 0.448975, peak moment 2.536108 N m, no damage or break; long `CONVERGED`, 17/16, utilization 4.331287, moment 26.029072 N m, first damage tick 0, first break tick 36, key 72 = (2,2)–(3,2). Long reanalysis gives components IDs 36 (3 cells) and 37 (14 cells), both `CONVERGED`. Results come from forces and the unchanged damage law, not span thresholds. Replay test executes twice and compares first failure tick/key. The runner rebuilds topology and reanalyzes each resulting component; it never manually breaks a bond. Invalid or unsupported status is not treated as stability.

The two-layer roof has 30 nodes/41 bonds, utilization 4.701951, displacement 0.001080709 m vs thin 0.002314010 m, first break tick 32, key 73 = (2,2)–(2,3); resulting components 19 (28 cells) and 53 (2 cells) both converge. The stiffer roof deflects less but its extra weight and lattice load redistribution increase peak utilization and cause earlier failure here; this is a model-specific result, not a universal thickness law.

Cantilever lengths 4 and 8 have max moments 24.525 and 88.290 N m. Independent discrete reference with P=2500×0.001×9.81=24.525 N per cell is `P*0.1*n*(n+1)/2`, exactly these values. For continuum `w*L²/2`, w=P/0.1, L=0.1n, values are 19.620 and 78.480 N m: the difference is the discrete end-cell load. Following failure, their free portions are `UNSUPPORTED` and do not fall. Island is `UNSUPPORTED`.

## Tests and timings

`gradlew.bat test build rockReferenceScenes` succeeds. The calibration test covers no damage for 600 short-roof ticks, progressive long-roof damage, reanalysis persistence, deterministic first failure, no stale snapshot, component rebuild, finite values, analytical cantilever and unsupported island. Existing tests cover oversized and numerical failure. No GUI was tested.

One exploratory Windows 11 / Java 25 run; no timing assertions, JIT affects first result. Milliseconds: short connectivity 0.034, assembly 3.645, solve 0.201, damage tick average 0.0077, total 17.070; long connectivity 0.042, assembly 0.839, solve 1.104, damage tick average 0.0052, post-break rebuild 0.235, total 2.534. See `gradlew.bat rockReferenceScenes` for all scene and component output. These small fixtures are not full-world structural performance.
