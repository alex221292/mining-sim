# M4.3b.2 — механика и повреждения без GUI

`World` владеет материалами, `RockConnectivity` — топологией связей, `RockMaterialRegistry` — неизменяемыми профилями, `RockDamageSystem` — повреждениями и диагностикой. Последняя создаётся с существующей связностью того же мира и не устанавливает второй change sink. После завершения связности вызовите `analyze(x,y)` для клетки камня: анализируется только её полный компонент, не весь мир. `snapshot()` доступен при `CONVERGED`. Снимок неизменяем, но после смены ревизии является историческим; нельзя считать его текущим. Неподдержанные, незавершённые, слишком большие и неуспешные расчёты не означают устойчивость. Для сброса повреждений и истории тиков создайте новую систему и отбросьте старые снимки. API однопоточный.

Узлы — клетки в построчном порядке, координаты `(0,1*(x+0,5), -0,1*(y+0,5))` м. Целые ортогональные связи становятся элементами рамы в каноническом порядке вправо/вниз; разорванные исключены. К каждому узлу один раз приложена сила вниз `плотность * 0,1³ * гравитация`; линейная масса элементов равна нулю, чтобы не считать вес дважды. Прямой контакт с bedrock закрепляет все три степени свободы узла; это сильное упрощение, а не крепление конечной прочности. На границах мира или компонента дополнительных опор нет. Предел — 64 узла/256 элементов, при превышении возвращается `TOO_LARGE`; компонент без опоры даёт `UNSUPPORTED`. Это небольшая решётка Эйлера—Бернулли, не проверенная геотехническая модель. Плотный метод Гаусса, пороги и ограничения float описаны в `m4-3a-frame_ru.md`.

Эталонное квадратное сечение: A=0,01 м², I=0,1⁴/12 м⁴, момент сопротивления Z=0,1³/6 м³. EA=E*A, EI=E*I. Профили содержат плотность в кг/м³, модуль Юнга и прочности в Па, скорость повреждения в с⁻¹. Для будущей границы разных пород `weakerInterface` берёт меньшие модуль и каждую прочность, большую скорость повреждения; вес клетки использует её собственную плотность. M4.2 пока распознаёт только STONE: добавление профиля само по себе не добавляет топологию или новый ID. Текущие значения профиля — игровые заглушки.

Для локальных концевых усилий `[N1,V1,M1,N2,V2,M2]` растяжение равно max(0,-N1,N2), сжатие — max(0,N1,-N2). Использование прочности равно max(растяжение/(A*прочность растяжения), сжатие/(A*прочность сжатия)) + max(|V1|,|V2|)/(A*прочность сдвига) + max(|M1|,|M2|)/(Z*прочность изгиба). `RockBondStrength` проверяет конечность значений. За тик повреждение растёт на `rate/60 * max(0, utilization-1)`, с ограничением 1; самолечения нет. Ключ повреждения — канонический ID связи и её incarnation. Удалённые/заменённые связи очищаются при следующем анализе; неизменённые сохраняют повреждение при пересчёте.

`advanceTick(id)` принимает строго возрастающие неотрицательные ID, разрешает пропуски без повтора и учитывает даже тик с незавершённым/неуспешным расчётом. Он добавляет не более одного приращения за 1/60 с; `analyze` и запросы время не продвигают. В каноническом порядке обновления подтверждаются до первой связи с повреждением 1; она разрывается через `RockConnectivity`, остальные ожидают новую топологию и равновесие. Компоненты и силы недействительны до завершения связности и нового `analyze`. Отображения трещин и движения фрагментов нет; они предназначены для последующих M4.3c и M4.4. Клетки камня после разрыва остаются в мире.

Ревизия проверяется вокруг сборки и решения и перед публикацией; тик требует актуального сходящегося снимка. Смена incarnation обнуляет старое повреждение даже при удалении и возврате клетки между анализами. Замена sink делает запросы связности недоступными; повторное подключение инвалидирует incarnation. `RockConnectivity` пока работает только со STONE; полный обход связности и полный поиск компонента в этой реализации не оптимизированы для больших миров. MSIM ничего из этого не сохраняет.

## Тесты и исследовательские измерения

`gradlew.bat test build` проходит; тесты покрывают аналитический вес колонны, приращение за тик, повтор тика, разрыв/замену, устаревание/ожидание, отсутствие опоры/превышение размера и консоль через границу чанка. Для калибровки необходимы дополнительные независимые тесты кровли, режимов отказа и производительности.

`gradlew.bat rockDamageBenchmark`, Windows 11 Java 25, один запуск, 20 повторных анализов/тиков, прочный тестовый профиль; время в мс, сборка включает поиск компонента и сборку матрицы, решение — восстановление усилий. Первый анализ включает JIT. Память не измерялась; плотному решателю нужны O((3N)²) памяти и O((3N)³) операций исключения.
