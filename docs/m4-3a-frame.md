# M4.3a planar frame solver

`PlanarFrameSolver` is an isolated small linear elastic 2D Euler–Bernoulli frame solver, not yet coupled to `World`, connectivity, ticks, damage or GUI. Nodes have global x/y displacement and rotation; supplied coordinates are metres (a world cell is 0.1 m), forces N, moments N m, axial rigidity EA N, bending rigidity EI N m², linear mass kg/m and gravity m/s². Global y points upward. Each element's uniform self-weight is converted to consistent local nodal forces and moments. Avoid also assigning the same mass as nodal load. Cross-section, thickness and density are represented only through user-supplied EA, EI and linear mass; no calibration is implied.

`addNode` and `addElement` order is authoritative and deterministic. The local stiffness from `PlanarFrameElement` is rotated and assembled into a dense global matrix; zero-displacement fixed DOFs are eliminated. Gaussian elimination uses deterministic partial pivoting with first-index tie breaks; no artificial stiffness or regularization is applied. A pivot at most 1e-12 of the largest reduced matrix entry is classified SINGULAR; poorly conditioned but physically solvable configurations may therefore also be reported singular. CONVERGED requires max free-DOF residual divided by max(1 N, max absolute applied free-DOF load) at most the supplied tolerance; numerical overflow or failed residual returns NON_CONVERGED. Results include global displacements and local element end actions [axial, shear, moment] at both ends, with consistent gravity loads subtracted. Failure results have no displacement/force data. Constrained reactions are not exposed. All floating-point calculations follow a fixed order but cross-platform bitwise equivalence is not promised.

The hard limit is 64 nodes (192 DOFs) and 256 elements, checked before allocating the dense matrix; oversized inputs return TOO_LARGE. Model input lists themselves grow as items are added. Runtime is O(DOF³), storage O(DOF²), making this unsuitable for a whole sandbox. Zero-length elements are rejected; free rigid-body mechanisms are singular, not stable. No iterative solver is used; `NON_CONVERGED` indicates numerical failure or excessive residual, not an iteration timeout. Methods are single-threaded and result arrays belong to the caller. Assembly and solution timing getters are diagnostics only, not used in physics decisions.

For the residual norm, moments in N m are numerically normalized using a 1 m reference length before comparison with forces in N. This simple scaling and the global pivot threshold are limitations for systems with extreme length or stiffness ratios.

`gradlew.bat planarFrameBenchmark`: Windows 11, Java 25, five warmups and ten timed runs per cantilever; assembly / solve including force recovery: 8 nodes 0.236 / 0.139 ms; 24 nodes 0.069 / 0.251 ms; 48 nodes 0.142 / 1.648 ms; 64 nodes 0.157 / 3.728 ms. Single exploratory run; JIT and machine noise affect results. `gradlew.bat test build` checks a closed-form cantilever, simply supported beam, self-weighted column, span scaling, singularity and size limit.
